##4. mkdir
mkdir creates a new directory.
Example:bashmkdir practice
##5. touch
touch creates an empty file.
Example:bashtouch file.txt
##6. cp
cp copies files or directories.
Example:bashcp file.txt backup.txt
##7. mv
mv moves or renames files.
Example:bashmv backup.txt old-backup.txt
##8. rm
rm removes files.
Example:bashrm old-backup.txt
##9. cat
cat displays the contents of a file.
Example:bashcat file.txt
##10. less
less displays a file one screen at a time.
Example:bashless file.txtPress q to exit.
##11. head
head displays the first lines of a file.
Example:bashhead file.txt
##12. tail
tail displays the last lines of a file.
Example:bashtail file.txt
##13. grep
grep searches for text inside files.
Example:bashgrep "Linux" file.txt
##14. find
find searches for files and directories.
Example:bashfind . -name "file.txt"
##15. chmod
chmod changes file permissions.
Example:bashchmod +x script.shThis gives the script execute permission.
##16. chown
chown changes the owner or group of a file.
Example:bashsudo chown user:user file.txt
##17. ps
ps displays information about running processes.
Example:bashps
##18. top
top continuously displays running processes and system resource usage.
Example:bashtopPress q to exit.
##19. df
df displays filesystem disk space usage.
Example:bashdf -hThe -h option displays sizes in a human-readable format.
##20. du
du displays disk usage of files and directories.
Example:bashdu -sh .
